# Expense Tracker

Expense Tracker adalah website sederhana yang digunakan untuk mencatat dan mengelola data pengeluaran.

Website ini dibuat menggunakan **HTML, CSS, dan JavaScript** serta tidak menggunakan backend atau database. Semua data pengeluaran dikelola langsung pada sisi client menggunakan JavaScript.

## Fitur

* Menambahkan nama atau keterangan pengeluaran.
* Menambahkan nominal pengeluaran.
* Menampilkan daftar pengeluaran yang sudah ditambahkan.
* Menampilkan jumlah data pengeluaran.
* Menghitung total seluruh nominal pengeluaran.
* Menghapus data pengeluaran.

## Cara Kerja

Pengguna mengisi nama pengeluaran dan nominal pada form, kemudian menekan tombol **Tambah Pengeluaran**. Data akan disimpan sementara dalam array JavaScript dan ditampilkan pada halaman.

Setiap kali data ditambahkan atau dihapus, JavaScript akan menghitung kembali jumlah data dan total nominal pengeluaran.

Website ini dibuat sebagai tugas Praktikum 3 HTML, CSS, dan JavaScript.
